# Pocket Pilot

Pocket Pilot is a web-based personal finance operating system for salary earners. It focuses on daily safe spend, financial health, goals, transaction tracking, analytics, and AI-style financial decisions.

## Implemented

- Responsive Vite React application.
- Feature-first source layout.
- Local-first persistence through a repository abstraction over `localStorage`.
- Dashboard with salary, safe spend, available balance, health score, bills, insights, and quick actions.
- Expense and income entry.
- Goals planner.
- Analytics screen with category and cash-flow breakdowns.
- Rule-based AI assistant and "Can I buy this?" purchase simulator.
- Settings for salary and fixed commitments.
- Unit tests for finance calculations.

## Run

```bash
npm.cmd install
npm.cmd run dev
npm.cmd test
npm.cmd run build
```
